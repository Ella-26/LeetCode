## 一、循环思路

```
┌────────────────────────────────┐
│ 1. 要重复做吗？                │
│    不知道次数 → while          │
│    知道次数   → for            │
├────────────────────────────────┤
│ 2. 每一轮干什么？（口语说出来）  │
│    把这句话翻译成代码           │
├────────────────────────────────┤
│ 3. 啥时候停？（写出条件）       │
│    把它塞进 while/for 里       │
└────────────────────────────────┘
```

| 写法 | 代码 | 结果 |
|------|------|------|
| 固定次数 | `for i in range(n):` | `i` = 0, 1, ..., n-1 |
| 指定范围 | `for i in range(a, b):` | `i` = a, ..., b-1 |
| 指定步长 | `for i in range(a, b, step):` | 如 `range(0,10,2)` → 0,2,4,6,8 |
| 直接遍历数组 | `for num in arr:` | 每轮自动取下一个值 |

## 二、常用内置函数

| 函数 | 作用 | 示例 |
|------|------|------|
| `len(x)` | 取长度（字符串、列表等） | `len([1,2,3])` → `3` |
| `abs(n)` | 取绝对值 | `abs(-5)` → `5` |
| `max(a, b)` | 两数取大 | `max(3, 5)` → `5` |
| `max(arr)` | 列表取最大 | `max([3,1,4])` → `4` |
| `max(arr, key=)` | 按条件取最大 | `max([-3,1,-4], key=abs)` → `-4` |
| `min(...)` | 用法同 `max`，取最小 | |
| `sum(arr)` | 求和 | `sum([1,2,3])` → `6` |
| `range(n)` | 生成 0 ~ n-1 | `list(range(5))` → `[0,1,2,3,4]` |
| `range(a,b)` | 生成 a ~ b-1 | `list(range(1,6))` → `[1,2,3,4,5]` |

**max 经典：**
```python
res = max(res, score)    # 不断更新最大值
res = max(0, res)        # 保证不下 0
```

## 三、字符串操作

| 操作 | 写法 | 示例 / 说明 |
|------|------|-------------|
| 长度 | `len(s)` | `len("abc")` → `3` |
| 取字符 | `s[i]` | 和数组一样 |
| 遍历 | `for ch in s:` | 一个个取 | 遍历每个元素本身，不是索引
| 转整数 | `int(s)` 或 `int(ch)` | `int("5")` → `5` |
| 转字符串 | `str(n)` | `str(123)` → `"123"` |
| 判断数字 | `ch.isdigit()` | `"5".isdigit()` → `True` |
| 全变小写 | `s.lower()` | `"ABC"` → `"abc"` |
| 全变大写 | `s.upper()` | `"abc"` → `"ABC"` |
| 首字母大写 | `s.title()` | `"hello world"` → `"Hello World"` |
| 仅首字大写 | `s.capitalize()` | `"hello"` → `"Hello"` |
| 统计字符数 | `s.count('0')` | `"1001".count('0')` → `2` |
| 找子串位置 | `s.find('ab')` | 找不到返回 `-1` |
| 以 xx 开头 | `s.startswith('abc')` | → `True` / `False` |
| 以 xx 结尾 | `s.endswith('xyz')` | → `True` / `False` |
| 分割 | `s.split(',')` | → `["a", "b"]` |
| 拼接 | `','.join(arr)` | `",".join(["a","b"])` → `"a,b"` |

> ⚠️ 字符串里的 `'0'` 和数字 `0` 是两回事！比较时要加引号。`s[i] == '0'` 不是 `0`。

## 五、十进制 → 二进制（短除法）

不断除以 2，余数**从下往上**读。

```
例：6 转二进制

3 ÷ 2 = 1  余 1
1 ÷ 2 = 0  余 1

结果：110 → 补齐 4 位，左边补 0：0110
```

## 六、位运算符

| 运算符 | 名称 | 规则 | 示例 |
|--------|------|------|------|
| `&` | 按位与 | 两边都是 1 才得 1 | `5 & 3` → `0101 & 0011` → `0001` → 1 |
| `\|` | 按位或 | 有一个为 1 就得 1 | `5 \| 3` → `0101 \| 0011` → `0111` → 7 |
| `^` | 按位异或 | 相同得 0，不同得 1 | `5 ^ 3` → `0101 ^ 0011` → `0110` → 6 |
| `~` | 按位取反 | 0 变 1，1 变 0 | `~5` → `-(5+1)` → -6 |
| `<<` | 左移 | 整体左移，右边补 0 | `1 << 3` → 8 |
| `>>` | 右移 | 整体右移，左边补 0 | `8 >> 2` → 2 |

**公式：** `x << n = x × 2ⁿ` `x >> n = x // 2ⁿ`

**`~x` 口诀：** `~x = -(x + 1)`，如 `~5` = -6, `~0` = -1, `~(-1)` = 0

## 七、位运算常见套路

| 操作 | 写法 | 示例 |
|------|------|------|
| 判断奇偶 | `n & 1` | `3 & 1` → 1（奇），`4 & 1` → 0（偶） |
| 判断 2 的幂 | `n > 0 and n & (n - 1) == 0` | `8` → ✅，`6` → ❌ |
| 乘 2 / 除 2 | `n << 1` / `n >> 1` | `5 << 1` → 10，`6 >> 1` → 3 |
| 交换两数（无临时变量） | `a ^= b; b ^= a; a ^= b` | |
| 取第 k 位 | `(n >> k) & 1` | `(5 >> 2) & 1` → 1 |
| 第 k 位设为 1 | `n \| (1 << k)` | `5 \| (1 << 1)` → 7 |
| 第 k 位设为 0 | `n & ~(1 << k)` | `5 & ~(1 << 0)` → 4 |
| 统计 1 的个数 | `bin(n).count('1')` | `bin(6).count('1')` → 2 |

## 八、列表（数组）用法

### 1. 创建

| 操作 | 写法 | 结果 |
|------|------|------|
| 空列表 | `arr = []` | `[]` |
| 定长全 0 | `arr = [0] * 5` | `[0, 0, 0, 0, 0]` |
| 直接初始化 | `arr = [1, 2, 3]` | `[1, 2, 3]` |

### 2. 基本操作

| 操作 | 写法 | 对比 Java |
|------|------|-----------|
| 长度 | `len(arr)` | `arr.length` |
| 取元素 | `arr[i]` | `arr[i]` |
| 改元素 | `arr[i] = 5` | `arr[i] = 5` |
| 取最后一个 | `arr[-1]` | `arr[arr.length-1]` |
| 取切片 [1,4) | `arr[1:4]` | 无 |
| 判断元素在不在 | `5 in arr` | 无 |
| 反转 | `arr[::-1]` | 无 |
| 排序（原地） | `arr.sort()` | `Arrays.sort(arr)` |
| 排序（新列表） | `sorted(arr)` | 无 |

### 3. 添加 / 删除

| 操作 | 写法 | 说明 |
|------|------|------|
| 末尾加 | `arr.append(val)` | `[1,2]` → `[1,2,val]` |
| 指定位置插 | `arr.insert(i, val)` | 索引 i 前插入 |
| 删最后一个 | `arr.pop()` | 返回被删值 |
| 删指定位置 | `arr.pop(i)` | 删索引 i |
| 按值删除 | `arr.remove(val)` | 删第一个匹配的 |

### 4. 遍历

| 方式 | 写法 | 适用场景 |
|------|------|----------|
| 直接取值 | `for word in words:` | 只关心每个元素本身 |
| 按索引 | `for i in range(len(words)):` | 需要用到索引 |
| 索引 + 值 | `for i, word in enumerate(words):` | 同时需要索引和值 |
| 只遍历一段 | `for i in range(left, right+1):` | 只需要某一段范围 |

```python
words = ["are", "amy", "u"]

# ① 只关心每个元素本身
for word in words:
    print(word)           # "are", "amy", "u"

# ② 需要用到索引
for i in range(len(words)):
    print(i, words[i])    # 0 "are", 1 "amy", 2 "u"

# ③ 只需要某一段
for i in range(0, 2):
    print(words[i])       # "are", "amy"
```

### 5. 二维列表

| 操作 | 写法 |
|------|------|
| 创建 rows×cols 全 0 | `[[0] * cols for _ in range(rows)]` |
| ❌ 错误写法 | `[[0] * cols] * rows`（所有行指向同一列表！） |
| 行数 / 列数 | `len(matrix)` / `len(matrix[0])` |
| 遍历 | `for i in range(rows): for j in range(cols):` |
